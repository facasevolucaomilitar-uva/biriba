# 🎖️ Simulador de Biriba - Evolução Militar

Aplicativo web interativo para personalização e encomenda de Biribas / Tarjetas Bordadas oficiais do Colégio Militar (12 cm × 2,5 cm) para Agasalho ou Farda, com direcionamento direto para o WhatsApp.

## 🚀 Como publicar no GitHub Pages (Passo a Passo)

1. Crie um repositório no GitHub com o nome `simulador-biriba` (ou o nome de sua preferência).
2. Envie os seguintes arquivos:
   - `index.html` (arquivo principal do simulador)
   - `manifest.json` (configuração para abrir e instalar como app no celular)
3. No seu repositório no GitHub, clique na aba **Settings** (Configurações).
4. No menu lateral esquerdo, clique em **Pages**.
5. Em **Branch**, selecione `main` e a pasta `/ (root)`, depois clique em **Save**.
6. Aguarde cerca de 1 minuto e o GitHub vai gerar o seu link oficial:
   `https://seu-usuario.github.io/simulador-biriba/`
